# TH_ExamGen - Hệ Thống Soạn Ma Trận & Đề Thi Tiểu Học GDPT 2018 (Bản Trực Tuyến)

Phần mềm tự động sinh ma trận, bản đặc tả và đề kiểm tra định kỳ Tiểu học chuẩn Thông tư 27 & Chương trình GDPT 2018 (SGK Kết nối tri thức với cuộc sống).

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/tongminhkhanh/TH_ExamGen)

## Tính Năng Nổi Bật

- **Môn Tiếng Việt:** 11 câu chuẩn Bộ GD (7 câu Đọc hiểu / 5.0đ + 4 câu Kiến thức Tiếng Việt / 3.0đ). AI tự sáng tác bài đọc ngoài SGK đúng chủ điểm hoặc tự nhập văn bản.
- **Môn Toán:** Đầy đủ trắc nghiệm & tự luận, các bước giải chi tiết và thang điểm cụ thể.
- **Xuất Word Chuẩn 100%:**
  - Trang 1: Bảng ma trận 10 cột khổ đứng A4 (Portrait) với tiêu đề UBND và Quốc hiệu.
  - Trang 2: Bản đặc tả chi tiết 13 cột khổ ngang A4 (Landscape) kèm khung phê duyệt 3 cột chữ ký.
  - Tải trực tiếp file `.docx` về máy tính/điện thoại chỉ với 1 click.
- **Triển khai WebApp:** Chạy trên Docker container nền tảng .NET 8, tương thích hosting miễn phí trên Render.com.

## Hướng Dẫn Triển Khai Lên Render.com (Miễn Phí)

1. Nhấn vào nút **Deploy to Render** ở trên hoặc truy cập:
   👉 **[https://render.com/deploy?repo=https://github.com/tongminhkhanh/TH_ExamGen](https://render.com/deploy?repo=https://github.com/tongminhkhanh/TH_ExamGen)**
2. Đăng nhập tài khoản Render bằng GitHub.
3. Nhập `GEMINI_API_KEY` (nếu có) hoặc để trống rồi nhập trên giao diện web.
4. Bấm **Apply** / **Deploy**. Render sẽ tự động dựng và cung cấp link WebApp trực tuyến cho bạn!
