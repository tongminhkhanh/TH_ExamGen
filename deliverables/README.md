# Thư mục Sản phẩm Bàn giao (Deliverables)

Thư mục này chứa các sản phẩm đầu ra hoàn thiện của dự án `TH_ExamGen`, bao gồm:
- Các bộ đề kiểm tra mẫu chuẩn theo Thông tư 27 (file Word `.docx`).
- Bản đóng gói ứng dụng Desktop chạy độc lập.
- Báo cáo kết quả kiểm thử, tài liệu hướng dẫn bàn giao cho khách hàng hoặc nhà trường.
