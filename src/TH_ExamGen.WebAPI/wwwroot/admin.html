Hệ thống TH_ExamGen hỗ trợ lưu trữ kép linh hoạt:
• Đám mây (Supabase PostgreSQL): Dữ liệu tồn tại vĩnh viễn trên đám mây, an toàn tuyệt đối khi Render tự khởi động lại hoặc nâng cấp mã nguồn.
• Dự phòng cục bộ (SQLite): Tự động kích hoạt khi chưa có chuỗi kết nối Supabase, đảm bảo hệ thống không bao giờ bị gián đoạn hay treo server.

Cách cấu hình Supabase trên Render.com:
1. Đăng nhập Supabase.com ➔ Tạo dự án mới ➔ Vào Project Settings ➔ Database.
2. Copy chuỗi URI kết nối (dạng: postgresql://postgres.[ref]:[password]@aws-0-ap-southeast-1.pooler.supabase.com:6543/postgres).
3. Mở Render.com ➔ Vào Web Service của bạn ➔ Environment ➔ Thêm biến: SUPABASE_CONNECTION_STRING và dán chuỗi trên vào.
📜 Đoạn Mã SQL DDL Tạo 3 Bảng (Chạy trên SQL Editor của Supabase)

Mặc dù hệ thống C# đã tự động chạy DDL tạo bảng khi khởi động, bạn có thể chạy đoạn SQL này trực tiếp trên Supabase SQL Editor nếu muốn xem hoặc tùy biến cấu trúc:

CREATE TABLE IF NOT EXISTS users ( id TEXT PRIMARY KEY, phone TEXT NOT NULL UNIQUE, password_hash TEXT NOT NULL, full_name TEXT, school TEXT, package_type TEXT DEFAULT 'Trial', expire_at TIMESTAMP WITH TIME ZONE, total_quota_remaining INT DEFAULT 1, daily_quota_limit INT DEFAULT 1, daily_generated_count INT DEFAULT 0, last_generated_date TEXT, last_generated_at TIMESTAMP WITH TIME ZONE, current_session_token TEXT, device_id TEXT, is_locked INT DEFAULT 0, created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP ); CREATE TABLE IF NOT EXISTS license_keys ( id TEXT PRIMARY KEY, key_code TEXT NOT NULL UNIQUE, package_type TEXT NOT NULL, days_duration INT NOT NULL, quota_amount INT NOT NULL, daily_limit INT NOT NULL, is_used INT DEFAULT 0, used_by_phone TEXT, used_at TIMESTAMP WITH TIME ZONE, created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP ); CREATE TABLE IF NOT EXISTS exam_logs ( id TEXT PRIMARY KEY, user_id TEXT NOT NULL, subject TEXT NOT NULL, grade INT NOT NULL, period TEXT NOT NULL, title TEXT NOT NULL, exam_data_json TEXT NOT NULL, tokens_consumed INT DEFAULT 0, created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP );
